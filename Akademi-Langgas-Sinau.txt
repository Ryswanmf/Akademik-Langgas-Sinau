Buatkan aplikasi web **Langgas Sinau Akademi** menggunakan:

* Laravel
* PHP 8.3+
* MySQL
* Blade Template
* Tailwind CSS
* Alpine.js

Jangan gunakan React, Vue, Bootstrap, Livewire, Filament, atau framework frontend lainnya.

## IDENTITAS

Nama aplikasi:

**LANGGAS SINAU AKADEMI**

Tagline:

**“Berdikari Mengenal Diri”**

Aplikasi ini merupakan sistem akademik dan absensi untuk LKP Langgas Sinau.

Sistem hanya memiliki 2 role:

* Admin
* Siswa

Tidak ada role instruktur.

---

## 1. LOGIN

Buat satu halaman login untuk Admin dan Siswa.

Desain login:

* Modern

* Responsive
* Menggunakan Tailwind CSS
* Logo Langgas Sinau
* Nama aplikasi
* Tagline

Setelah berhasil login:

Admin diarahkan ke:

`/admin/dashboard`

Siswa diarahkan ke:

`/siswa/dashboard`

# 5. AUTHENTICATION

Gunakan authentication Laravel yang sederhana.

Jika menggunakan starter kit, gunakan Laravel Breeze dengan Blade.

Jangan gunakan Livewire.

Implementasikan:

* Login
* Logout
* Password hashing
* Authentication middleware
* Role middleware

Buat middleware:

`AdminMiddleware`

dan:

`StudentMiddleware`

Pastikan siswa tidak dapat mengakses route admin meskipun mengetik URL secara manual.

# 10. SECURITY

Pastikan:

* Semua form menggunakan CSRF
* Gunakan Form Request atau validation Laravel
* Password menggunakan hashing Laravel
* Gunakan middleware role
* Gunakan authorization/policy jika diperlukan
* Siswa hanya dapat melihat data dirinya sendiri
* Siswa tidak dapat mengakses data siswa lain melalui URL
* Admin dapat mengakses seluruh data
* Validasi upload file
* Lindungi file sertifikat dan bukti izin

Jangan hanya menyembunyikan menu. Semua akses harus tetap diamankan di backend.
